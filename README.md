Проект: Предсказание конверсии пользователей для "Сбер Автоподписка".
Роль: ML-инженер

Бизнес-ценность проекта:
Разработанный сервис позволяет в реальном времени определять «горячих» пользователей на сайте. 
Это дает бизнесу возможность оптимизировать затраты на рекламу, 
таргетировать спецпредложения только на склонных к конверсии клиентов и снизить стоимость привлечения (CPA).

Что именно я сделал в рамках этого проекта:

1. Подготовка данных (ETL и EDA)
  - Собрал один общий датасет из двух разных источников: сессий ga_sessions и логов активности ga_hits.
  - Очистил данные от дубликатов, заполнил или удалил пропуски, привел типы данных в порядок.
  - Посмотрел на графиках, как распределяются ключевые признаки (устройства, операционные системы, география и реклама).

2. Создание признаков (Feature Engineering)
  - Самостоятельно собрал целевую переменную (таргет 0/1) на основе списка целевых действий на сайте из ТЗ.
  - Создал новые полезные признаки, объединяя данные о браузерах, операционных системах и рекламных кампаниях, чтобы помочь модели лучше находить закономерности.
  - Закодировал категориальные признаки и отмасштабировал числа, чтобы подготовить данные к обучению.

3. Обучение моделей и валидация
  - Разделил данные на выборки и настроил кросс-валидацию, чтобы модель не переобучалась и выдавала честный результат.
  - Обучил несколько разных алгоритмов бинарной классификации (от простых базовых до сложных ансамблей).
  - Оценил качество по метрике ROC-AUC. Заданный в ТЗ порог в 0.65 был успешно преодален — итоговый результат на тесте составил 0.7055.
  - Вывел важность признаков (Feature Importance), чтобы понять, какие именно параметры сильнее всего влияют на целевое действие.

4. Разработка API и подготовка к продакшену
  - Объединил весь код предобработки данных и предсказания модели в один готовый Python-скрипт (pipeline.py).
  - Написал локальный веб-сервис на базе FastAPI, который принимает на вход JSON-строку с параметрами сессии пользователя и мгновенно возвращает ответ 0 или 1 (main.py).
  - Замерил скорость работы сервиса — ответ возвращается быстрее 3 секунд, как и требовалось по регламенту ТЗ.

Стек технологий:
Python, Pandas, NumPy, Scikit-Learn, Lightgbm, Joblib, FastAPI

Результаты:
  - Итоговая метрика качества ROC-AUC на отложенном тесте: 0.7055.
  - Код полностью production-ready: пайплайн предобработки сырых данных автоматизирован и встроен в инференс-скрипт.
  - Модель успешно бьет baseline и готова к интеграции в реальный веб-интерфейс через развернутый FastAPI-эндпоинт.
